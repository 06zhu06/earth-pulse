# EARTH PULSE — 全球地震活动监测与时空演化分析平台

## 项目定位

EARTH PULSE 面向**地震活动研究员（Seismic Research Analyst）**，把全球历史地震记录转化为可筛选、可回放、可比较的时空地震活动图谱。

核心叙事：**全球监测 → 历史回放 → 空间分析 → 地震事件研究 → 研究结论输出**。

应用不提供实时预警、地震预测、震害评估或应急指挥结论。

## 数据来源与真实性

- 数据集：[Kaggle — Earthquake Database / USGS](https://www.kaggle.com/datasets/usgs/earthquake-database?resource=download)
- 文件：`database.csv`
- 数据文件大小：2,397,103 bytes（约 2.3 MB），小于 25 MB，无需采样或聚合。
- 记录数：23,412 条；清洗后有效地理/时间/震级/深度记录：23,412 条。
- 时间范围：1965—2016（以数据中的 `Date` / `Time` 为准）。
- 每行含义：一条地震或其他地震相关记录。
- 主要字段：`Date`、`Time`、`Latitude`、`Longitude`、`Magnitude`、`Depth`、`Type`、`Magnitude Type`、`ID`、`Source`。
- 数据性质：这是 Kaggle 上的 USGS 历史快照。它适合历史描述性分析；当前应用不把它包装成实时监测或地震预测系统。

## 仪表盘为谁服务

研究员每天查看历史回放或新增同步数据，用于发现地震活动的时间变化、空间聚集和震级—深度关系。

决策句：**如果研究员在当前时间窗口看到某区域出现高震级、浅源或事件密集现象，就会把该时间窗口/事件加入后续研究清单并导出 CSV，进行更深入的地震学核查。**

### 没有仪表盘时

研究员需要在 CSV 中手动筛选日期、震级、深度并复制坐标，再分别制作地图和统计图；重复分析耗时，且容易遗漏时间窗口和筛选条件。

### 为什么使用仪表盘

这是一个需要反复查看和改变筛选条件的探索任务。仪表盘可以把相同的研究问题放在统一视图中，让地图、趋势、深度关系和事件详情同步变化；邮件或静态周报不适合历史回放和交互式空间筛选。

## 页面设计

### 顶部

- EARTH PULSE 品牌和中英文标题。
- 数据期、来源和“历史快照/不提供实时预警”说明。

### 三个核心 KPI

- 当前事件数
- 当前最大震级
- 当前平均震级
- 额外显示浅源事件数量，帮助快速识别浅源活动。

### 主视觉

- 深色全球地理地图。
- 点位置：纬度/经度。
- 点大小：震级。
- 点颜色：震源深度（km），颜色不表示危险等级。
- 年度/月度时间轴：拖动时间轴，地图显示截至当前时间点的累计事件，实现历史回放。

### 支持图表

1. 年度事件数量柱状图，并用颜色编码平均震级，解释活动趋势。
2. 震级—深度散点图，解释震级和震源深度关系。
3. 可旋转 3D 地球散点图，展示全球地震点在地球表面的空间位置。
4. 经纬度—深度 3D 散点图，将震源深度作为垂直维度观察浅深层结构。

### 研究详情

- 事件选择器。
- 事件唯一 ID、日期、位置、震级、深度、来源、状态。
- 当前筛选事件表。
- 下载当前筛选事件 CSV。

## 明确删减的内容

1. **不展示震害损失、人口暴露或安全等级地图**：数据没有人口、建筑、损失和伤亡字段，制作这些图会制造无法验证的风险结论。
2. **不展示十几张按数据源/误差/站点数拆分的图表**：这些字段适合质量审计，但不会改变研究员的第一步空间研究决策；它们会分散主地图和趋势图的注意力。

## 数据可能造成的误读

- 地震事件密度不等于震害风险；页面底部明确提示缺少暴露和损失数据。
- 深度颜色不是风险等级；页面图例和侧栏均标注颜色含义。
- `Magnitude Type` 是测量方式，不同震级类型不应直接无条件比较；它在事件详情中保留用于解释。
- 多个记录可能存在缺失误差字段；应用不静默补造误差值，只在数据读取时保留原始缺失。
- 这是历史 Kaggle 快照，不是实时数据流。

## 刷新策略

当前提交的是冻结快照。生产版本建议每日从可信公开地震源同步，研究员按日查看；实时刷新不属于本项目承诺。数据过期一天可能使新事件不出现在研究列表，但不会改变历史研究结果；因此页面明确显示数据期和快照性质。
